# phonics-alphabet-song

알파벳 노래 오디오 — 어린이 영어 파닉스 워크북(알파벳 + 단모음 입문)용 음원입니다.

## 파일

- `alphabet-song.mp3` — 알파벳 챈트 (A–Z, 이름 → 소리 → 단어), 약 1분 53초

## 사용법

워크북의 노래 페이지(p3)에 있는 QR 코드를 찍으면 이 음원이 재생됩니다.
이 파일은 워크북 구매자가 로그인 없이 들을 수 있도록 공개 저장소에 올려두었습니다.

## 출처

- 음원: 알파벳 노래 챈트 (워크북의 노래 페이지와 동일한 순서·단어·소리)
- 워크북: 알파벳 + 단모음 파닉스 워크북 (별도 판매)
